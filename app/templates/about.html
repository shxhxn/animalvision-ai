How AnimalVision AI Works

AnimalVision AI classifies animal photos using a Convolutional Neural Network (CNN) trained entirely from scratch — no pretrained weights, no transfer learning. Every parameter in the model learned directly from the Animals-10 dataset.

What is a CNN?

A CNN is a type of neural network built specifically for image data. Instead of looking at every pixel independently, it slides small filters across the image to detect patterns: edges, textures, shapes, and eventually whole objects like "ear" or "fur texture." Early layers learn simple patterns; deeper layers combine those into increasingly complex, animal-specific features.

The architecture

  1. Rescaling — raw pixel values (0–255) are normalized to 0–1, which helps the network train more stably.
  2. Data augmentation — during training, images are randomly flipped, rotated, and zoomed. This exposes the model to more variety than the raw dataset alone contains, reducing overfitting.
  3. Four convolutional blocks — each block has two convolutional layers followed by batch normalization, a ReLU activation, max-pooling (which halves the image resolution), and dropout. Filter counts double at each block (32 → 64 → 128 → 256), so the network learns more detailed features as the spatial resolution shrinks.
  4. Global average pooling — condenses each feature map down to a single number, keeping the parameter count low and reducing overfitting compared to a traditional flatten + dense approach.
  5. Dense output layer — a final softmax layer outputs a probability for each animal class, which is what powers the confidence percentages you see on the Predict page.

How training works

The model sees the training images repeatedly (each full pass is called an "epoch"), adjusting its internal weights after each batch to reduce its prediction error. A held-out validation set — images the model never trains on — is checked after every epoch to make sure it's actually generalizing, not just memorizing. Training automatically stops early if validation performance stops improving, and the best version of the model (by validation accuracy) is the one that gets saved, not necessarily the last one.

How predictions work

When you upload a photo, it's resized to 128×128 pixels and fed through the trained network. The output is a probability distribution across all animal classes — the "Top 5 Predictions" chart on the Predict page shows the five highest, so you can see not just the model's best guess but how confident it was relative to the alternatives.

Curious how well the model actually performs? Check the Model Performance page for accuracy/loss curves, a confusion matrix, and precision/recall/F1 scores measured on a held-out test set.
